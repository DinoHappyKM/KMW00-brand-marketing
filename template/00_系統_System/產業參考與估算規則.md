# 產業參考與估算

使用者不知道時先規劃，不逐題追問。來源優先：使用者單據與紀錄→當地官方／產業協會／可核對供應商價目→有方法與日期的市場資料→透明工作假設。沒有來源不可冠名「業界標準」。跨國、地區、規模或服務不同不得直接套用。

對每個參考數值保存：項目、value（含單位／區間）、basis、source（網址／資料名稱／未取得）、date、region、confidence、status=estimated、待驗證方式。記到可讀接續文件的估算區及成本工作表；JSON assumptions為選用鏡像。模型記憶不能當成本證據；涉及現行價格或法規應查原始來源。無法查證即標工作假設，不因估算而停止草圖。

成本拆算：單位變動成本=材料／進貨+直接人工時間×時薪+包裝+運費負擔+平台／金流費+損耗。固定費用另列，每單分攤依預計單量。創辦人工時也不能自動當零。提供低／中／高情境，列出哪些數值是使用者資料、參考或假設。

貢獻金額=售價−單位變動成本；完整損益還要扣固定費與其他費用。完整成本未確認，不把試算稱為真實毛利，不承諾折扣後一定賺錢。可以給待確認方案、成本上限與損益敏感度；正式價格發布需品牌核准。
