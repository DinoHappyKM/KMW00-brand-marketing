# 成交類型判定

| 類型 | 模式 | 核心路徑 | 是否主要 |
|---|---|---|---|
| A | 內容成交型 | 內容 → 受眾池 → 體驗 → 成交 |  |
| B | 合作成交型 | 需求 → 合作 → MVS → 案例 → 轉介紹 |  |
| C | 門市成交型 | 在地曝光 → 到店 → 體驗 → 會員 → 回訪 |  |
| D | 社群成交型 | 社群 → 活動 → 團購／直播 → VIP |  |
| E | 陌生開發型 | 名單 → 訪談 → 提案 → 成交 → 長約 |  |
| F | 電商檔期型 | 引流 → 商品頁 → 優惠 → 加購 → 回購 |  |
| G | 高客單顧問型 | 權威 → 診斷 → 提案 → 高價成交 → 案例 |  |

判定時看「目前主要靠什麼完成成交」，不是只看產業名稱。
