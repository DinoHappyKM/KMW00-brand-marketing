# KMW00 品牌行銷｜公開測試版

黃嘉偉品牌行銷工作流程；正式中文名稱待定。支援Windows／Mac的Codex本機品牌資料夾初始化。這是公開測試版，不是已上架ChatGPT Plugin。

## 開始試用
1. 在Codex建立或選取一個專用空資料夾。
2. 使用 [安裝提示詞](INSTALL_PROMPT.txt)，或依 [安裝說明](INSTALL.md) 操作。
3. 安裝後把品牌資料夾設為Codex專案，輸入「開始KMW00」。

首次一次列完整開案問題，可回答不知道；依有來源的產業參考或清楚標示的假設先做規劃。成本使用區間及透明拆算，不當作品牌真實成本。

流程：品牌→A～G成交分類→現況路徑與斷點→商品與成本→CI／顧客資料→優先動作→保存接續。

## 資料歸屬
本倉庫只放方法、空白模板及工具。學員資料保存在私人工作區；不推送至本倉庫。安裝器不覆蓋非空資料夾；重複執行不升級、不重置進度。

## 本版範圍
- 共用品牌模板與Windows／Mac各自的初始化腳本；安裝不要求Python。
- 通用generic_only流程，未提供產業模組安裝及自動跨端同步。
- 手機／平板ChatGPT外掛是後續交付；本倉庫尚不代表已安裝手機技能。
- [測試狀態](TESTING.md)、[版本變更](CHANGELOG.md)、[來源](PROVENANCE.md)。

公開可閱讀與下載作課堂測試；未另授權開源再散布或商業授權。發布測試版不代表學員設備與實際成交成效已驗收。
