# KMW00 品牌行銷｜公開測試版
黃嘉偉品牌行銷工作流程；正式中文名稱待定。Windows、Mac、Linux共用品牌規則，手機／平板以可讀文件接續。本套件不是已上架ChatGPT外掛。

## 開始使用
- 電腦Codex：使用[第一段：電腦安裝提示詞](INSTALL_PROMPT.txt)，先在指定私人本機資料夾安裝。雲端保存為選用。Windows工具故障時可雙擊解壓後的Start-Windows.cmd；詳見[電腦故障處理](DESKTOP_TROUBLESHOOTING.md)。
- 手機／平板ChatGPT專案：使用[第二段：手機啟動提示詞](MOBILE_INSTALL_PROMPT.txt)，依[手機流程](MOBILE.md)建立或接續。
- 兩端都直接使用指定資料夾，下面直接是00系統、10品牌、20行銷等分類，不再包KMW00-XXX。
- 輸入「開始KMW00」。初次問題一次列完，已有資料先帶入；不知道可用有來源的產業參考或透明假設，估算不等於實際成本。

## 共用資料
四個核心文件、各品牌文件與「90_專案_Project/跨裝置接續」是日常接續資料。手機可用Google Docs或經實測可讀的MD／TXT；JSON只作選用工具快照，不再阻止手機規劃或可讀匯出。
需要跨端保存時，同一品牌選一個私人雲端資料夾作跨端保存來源；電腦本機副本在使用前讀最新版、保存前比對。沒有自動雙向同步。Google Docs需透過可用連接工具讀寫，不是把.gdoc捷徑當MD。
無Drive寫入工具時可交付可讀TXT與ZIP；如實標「尚未存入Drive」。能搜尋檔名不等於讀到正文，加入專案來源不等於所有文件已讀取。
