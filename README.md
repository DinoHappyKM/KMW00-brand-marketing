# KMW00 品牌行銷｜公開測試版

黃嘉偉品牌行銷工作流程；正式中文名稱待定。提供 Windows／Mac 本機與 Linux 雲端工作區初始化。這是公開測試版，不是已上架 ChatGPT Plugin。

## 開始試用
- 電腦 Codex：在專用品牌資料夾使用 [安裝提示詞](INSTALL_PROMPT.txt)，或依 [安裝說明](INSTALL.md) 操作。
- 手機／平板／網頁：使用 [手機啟動提示詞](MOBILE_INSTALL_PROMPT.txt)，先讀 [手機與 Google Drive 流程](MOBILE.md)。有可寫工作區的 Linux 可正常初始化，不能僅因作業系統就停止。
- 完成後輸入「開始KMW00」。首次一次列完整開案問題，可回答不知道；成本使用有來源的區間或透明工作假設，不當作實際成本。

流程：品牌→A～G成交分類→現況路徑與斷點→商品與成本→CI／顧客資料→優先動作→保存接續。

## Google Drive 與手機的能力邊界
把資料夾加入「資料來源」、使用相同帳號或完成認證，不等於該對話有建立資料夾、上傳、更新和讀回的工具。先檢查當次可用動作與目標資料夾權限。

- 有 Drive 寫入工具且目標資料夾讀寫驗證通過：依上傳清單建立分類資料夾，逐檔保存原始 MD／JSON 並讀回驗證。
- 只有讀取工具：仍可在可寫雲端工作區開始規劃，交付私人 ZIP 與手機接續 MD，標明「尚未存入 Drive」。
- 只有對話／網頁閱讀：提供可複製接續內容，不宣稱下載、安裝或保存完成。

雲端工作區、Google Drive、ChatGPT 專案來源是三個不同位置；本版不會自動同步，也不會增加帳號權限。

## 資料歸屬與版本
本倉庫只放方法、空白模板及工具。學員資料保存在私人工作區，不推送至本倉庫。安裝器不覆蓋非空資料夾；重複執行不升級、不重置進度。保留 v0.1.0-beta.1；新功能使用 v0.1.0-beta.2，未發布標記時必須記錄實際 commit，不把 main 稱為固定版。

本版只支援 generic_only，未提供產業模組與自動跨端同步。[測試狀態](TESTING.md)、[版本變更](CHANGELOG.md)、[來源](PROVENANCE.md)。公開可閱讀與下載作課堂測試；未另授權開源再散布或商業授權。程式測試不代表學生手機的 Google Drive 寫入已驗收。
